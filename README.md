# Lake Trio Events

Add **Uxie, Azelf, and Mesprit** as a connected set of Generation IV legendary encounters across Kanto and Hoenn.

After catching Articuno and encountering both Lugia and Ho-Oh, **Uxie** appears deep within Seafoam Islands while **Azelf** waits in Victory Road. Catching both unlocks the final encounter: **Mesprit**, found beside the lake on Hoenn's Route 120.

Each member of the Lake Trio appears at **Level 50** and uses an animated overworld sprite through Untamed Advanced. If one is defeated or escaped from instead of caught, it can be encountered again on a later visit.

## Features

- Uxie encounter in Seafoam Islands
- Azelf encounter in Victory Road
- Mesprit encounter on Hoenn Route 120
- Progressive unlock structure connecting all three encounters
- Level 50 legendary battles
- Animated Untamed Advanced overworld sprites
- Legendary encounters remain obtainable if defeated or escaped from

## Requirements

- [Untamed Advanced](https://github.com/goldenroddeptstore/Untamed-Advanced)
- [National Dex Gen 3](https://github.com/poooooby/national_dex_gen3)
- [Hoenn Journey](https://github.com/TheOriginalDrJ/Hoenn-Journey)

The Lake Trio events are intended for a playthrough with **Hoenn Journey** installed. Mesprit's encounter uses Hoenn Route 120.

## Installation

Install the required mods, then install **Lake Trio Events** through G1R Deluxe's mod browser or import the mod ZIP manually.
